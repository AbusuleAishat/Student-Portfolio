# Aishat Abu-sule — Student Portfolio

A personal portfolio and academic management website for Aishat Ikpemosi Abu-sule, a Software Engineering student at MIVA Open University. It introduces her, showcases projects, and provides an academic planner.

## Features

- Home page with an introduction and profile photo
- About page with personal and academic information
- Projects showcase
- Academic planner
- Contact page
- Responsive navigation and shared styling

## Pages

- `index.html` — Home and personal introduction
- `about.html` — About me
- `projects.html` — Projects
- `planner.html` — Academic planner
- `contact.html` — Contact

## Project structure

```text
.
├── images/       # Profile and project images
├── js/           # Page interactions and planner/contact scripts
├── styles/       # Shared stylesheet
├── video/        # Personal introduction video
├── about.html
├── contact.html
├── index.html
├── planner.html
└── projects.html
```

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static web server.

## Customize

Update the HTML pages and files under `images/`, `video/`, `js/`, and `styles/` to change the portfolio content, media, interactions, and appearance.
